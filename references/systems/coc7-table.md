# CoC7 桌上系统包

适用：7版核心、1920年代普通调查员；本地 v1.2.1 中文译本结合 Chaosium 官方规则。先读 [核心计算与页码](coc7-procedures.md)，本页补齐开团操作、资源和场景调用。快启固定技能分配、Pulp、幸运消耗、现代年代以及同人能力必须另列配置。这里的完整操作范围为普通调查、近战、常规单发枪械、步行追逐和幕间；自动火力、载具碰撞和法术仪式仍按具体条目加载，不用相邻机制代算。

## 角色创建的完成条件

按核心程序依次处理属性生成、年龄、职业、职业/兴趣预算、派生值、技能专长、人物联系及财产。不能因公式齐全就宣布车卡完成。交付须明确生成方法与骰子记录；使用预设测试属性时写明。每项职业技能核对职业表，信用评级从职业池中实际扣除。人物背景至少给外貌、信念、重要之人、意义地点、宝贵之物、性格与一个玩家选择的关键连接。

[记者卡](../../assets/examples/coc7-journalist.md) 是可直接选择的预设。演练中使用以下已固定补充：28岁港区记者，短发、墨渍袖口；信念为保存可核实记录；重要之人为姐姐林岚；意义地点为报社资料室；宝贵之物为第一篇报道的剪报；性格谨慎但愿意追问；关键连接选剪报。同行理由为受家属委托核实失踪。没有旧伤、恐惧、神话知识或魔法。服饰、纸笔和证件为普通职业用品，不携带相机或枪械；不再保留“待借相机”选项。用于真人时玩家可改上述原创设定。

信用评级20处于标准生活水平；现金和资产按本地核心“现金与其他资产”表现场确认，禁止将20直接当成20美元。若该表无法读取，先以无购物的短模组开团，将金额记为待核验；不能把这样的卡标成财产核验已完成。大额购买超日常消费限额时扣全额现金，不只扣超出部分；变现资产须经过时间和具体行动。来源：本地核心PDF79–80。完整财产补充见记者卡末节。

## 每次检定的决策树

无不确定性或无实质风险 → 直接给结果；有风险 → 先说技能、难度、失败后果与可用修正 → 玩家掷骰 → 成功等级 → 是否达到任务难度 → 后果 → 成长与资源。技能检定失败后若玩家改变方法并投入风险，可提出一次孤注一掷；先说明加重后果。战斗、SAN、幸运和普通对抗不能靠重复尝试无限推进。

奖励骰共享个位，十位0与个位0组合成100。技能49、骰96为大失败；技能50、骰96为失败；100始终大失败，01为大成功。工具 `coc_result` 只算等级，不替 KP 选难度。两个普通成功对抗通常按技能值处理平手；近战使用专门规则。

## 战斗现场表

| 步骤 | 必须记录 | 例外检查 |
|---|---|---|
| 开始 | 参与者DEX、位置、武器、已准备状态、先前防御次数 | 准备就绪枪械先攻按核心枪械段；不把叙事轮强行固定12秒 |
| 近战 | 攻击技能、目标选择闪避/反击、双方出目和等级 | 同级成功：闪避方胜，反击时发起方胜；双方失败无伤害 |
| 多人围攻 | 防守者本轮已闪避/反击次数 | 普通单次攻击者防守过后，后续攻击者获1奖励骰；不累计给防守者惩罚骰；多攻击生物另看次数 |
| 战技 | 明确解除武器/压制/推开等目标、Build差 | 攻击方低1/2级给1/2惩罚骰；低至少3级不能常规发动 |
| 极难命中 | 武器能否贯穿、是否主动攻击 | 反击不获得主动极难攻击同样的伤害提升；伤害加值与武器骰分列 |
| 伤害 | 原始骰、DB、护甲、实际损失、最大/当前HP、重伤 | 单次至少半最大HP判重伤；单次至少最大HP死亡按当前官方Wiki |
| 回合末 | 昏迷、濒死CON时机、NPC撤退条件 | 逃走、投降、求援均是有效NPC行为，不默认战斗到死 |

证据：核心PDF87–94、102–104；[官方主持屏](https://www.chaosium.com/content/FreePDFs/CoC/CHA23130%20-%20Horror%20on%20the%20Orient%20Express/CHA23144%20-%20Horror%20on%20the%20Orient%20Express%20Keeper%20Screen.pdf) 的 Combat/Outnumbered；[官方伤害规则](https://cocwiki.chaosium.com/rules/hit-points-wounds-and-healing.html)。2014主持屏伤害表用“超过最大HP”，与当前Wiki的等号不同，死亡条件采用后者并保留冲突记录。

### 常规枪械操作卡

装弹数、当前弹药、射程和故障值必须从具体武器表加载。枪械通常不进行近战式对抗。基础射程普通、两倍困难、四倍极难；目标飞扑掩体成功给射手惩罚骰；近距离（DEX五分之一英尺内）与瞄准一轮可给奖励骰。手枪一轮多发时每发受惩罚骰，分别消耗子弹、判命中和伤害。飞扑掩体的后续行动损失查核心枪械段，不能免费躲每颗子弹。这里不支持用“多发手枪”模拟自动扫射。

### 伤害与医疗交接

重伤标记不能由一次治疗自动消除。急救1小时内成功恢复1HP；医学通常耗1小时、恢复1d3；重伤周恢复、轻伤日恢复分开。0HP无重伤为昏迷；有重伤为濒死。下一轮末开始CON；急救暂时稳定和后续医学须记录两个阶段、救治者、已尝试记录、下一小时CON。立即死亡不能用普通急救逆转。工具 `coc_injury` 不替代这些计时器。

## 理智与追逐

SAN ledger 至少含：当前SAN、上限、日界起始SAN、本日累计、刺激ID/损失式、INT判定、发作剩余轮数、潜在疯狂截止、已习惯恐惧。一次损失5点先检查INT；本日累计达到起始SAN五分之一检查不定性疯狂。`coc_sanity` 返回阈值旗标，不替玩家决定发作内容；正在发作不再扣SAN，发作后不能继续免疫全部刺激。来源：核心PDF133–136。

步行追逐先处理CON速度骰，再排除已经逃脱者，留下参与者设置地点链、DEX序、MOV和AP。最慢参与者1AP，其他人每多1MOV多1AP。每步先扣AP，再处理地点障碍的成本/技能/伤害；玩家可选择谨慎通过、停止、协助或脱离。危险地点须在接近时提供可观察预兆。来源：核心PDF115–117。

## 幕间与缺失资料

逐技能确认成功使用资格；信用评级和神话不勾成长。每个标记只作一次成长骰；高于现技能或>95才加1d10，然后清标。增加神话后重算SAN上限；成功跨90的SAN奖励按具体条文处理。恢复、就业变化和关键连接分别记录，不能用“升级一级”全体回满。

若请求未知法术：记录书名、版本、法术名、目标；先检索本地对应条目。未找到时暂停法术结算，给出可以继续的非该法术行动，不虚构MP、SAN成本。若玩家提交六版角色，保留原卡，重新核验属性尺度、技能和HP；不直接乘5后宣布迁移完成。

主持连续性见 [账本](../session-runtime.md)。每个场景至少准备一个无需秘密答案即可采取的行动、关键线索的替代获取途径和合理撤退路线；不可把调查成功率等同于玩家是否猜中KP心里的词。
