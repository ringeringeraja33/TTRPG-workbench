# CoC7：创建、结算与长期状态

本页是对用户本地《COC7th核心规则书v1.2.1.pdf》的原创操作性归纳。以下引用均为该文件**从1开始的PDF页序**；除明确标注外，印刷页码未逐页目视复核。译本不等于官方勘误版；发现的冲突见末节。第六版、快启、Pulp及扩展规则不得直接混入。书目：[COC-LOCAL-CORE](../bibliography.md#coc-local-core)。

## 1. 核心书点数法创建

先固定年代、职业、年龄、生成方式、技能上限与允许扩展。属性、职业点与兴趣点是三种不同资源。掷骰由约定的真实工具或玩家执行；以下示例均为指定测试输入。

| 项目 | 执行方法 | 来源PDF |
|---|---|---|
| STR、CON、DEX、APP、POW | 各3d6×5 | 23–24 |
| SIZ、INT、EDU | 各(2d6+6)×5 | 23–24 |
| 幸运 | 3d6×5；15–19岁另有两次取高 | 24–25 |
| 半值、五分之一 | 分别向下取整；主值改变后重算 | 25 |
| 初始SAN / SAN上限 | POW / 99−克苏鲁神话 | 24、134 |
| MP / HP | POW÷5 / floor((CON+SIZ)÷10) | 24、26 |
| 兴趣点 | INT×2，可投入职业技能；默认不能买克苏鲁神话 | 28 |
| 职业点 | 查所选职业公式；不要统一套EDU×4 | 28、31–32 |

年龄修正在分配职业点前处理。创建时选一个年龄档，不把低年龄档重复累加：

| 年龄 | 属性调整 | EDU改善次数 | MOV减少 |
|---|---|---|---|
| 15–19 | STR与SIZ合计−5；EDU−5；幸运两次取高 | 0 | 0 |
| 20–39 | 无年龄扣减 | 1 | 0 |
| 40–49 | STR/CON/DEX合计−5；APP−5 | 2 | 1 |
| 50–59 | 三项合计−10；APP−10 | 3 | 2 |
| 60–69 | 三项合计−20；APP−15 | 4 | 3 |
| 70–79 | 三项合计−40；APP−20 | 4 | 4 |
| 80–89 | 三项合计−80；APP−25 | 4 | 5 |

EDU改善：d100高于当前EDU才增加1d10，上限99。连续检定使用更新后的EDU。来源PDF25–26。战役中跨越年龄门槛用另一个累进程序（PDF82），不能再扣一遍创建总额。

伤害加值DB与体格Build共同由STR+SIZ决定（PDF25）：2–64为−2/−2；65–84为−1/−1；85–124为0/0；125–164为+1d4/+1；165–204为+1d6/+2。更大的怪物查完整表，不外推人类区间。

MOV（PDF26）：STR与DEX都小于SIZ时7；都大于SIZ时9；其余8，然后减年龄修正。“一项相等”归入其余；这不是DEX单独决定的速度。

分配台账每行保留：技能专长、基础值、职业投入、兴趣投入、总值、半值、五分之一、来源。职业信用评级范围必须满足，不能把信用评级当成可以直接花掉的现金。武器专长、其他语言、科学等写到具体子技能。未分配职业点不能转入兴趣池。职业例：记者EDU×4、信用评级9–30；私家侦探EDU×2+(DEX或STR)×2、信用评级9–30；教授EDU×4、信用评级20–70。各自技能名单不同（PDF28、31–32）。

### 创建数值演算

测试人物为28岁记者。给定年龄处理后的STR50、CON60、SIZ65、DEX70、APP55、INT75、POW60、EDU70，幸运50；年龄改善测试输入60不高于EDU，故EDU保持70。职业池280，兴趣池150，HP12，MP12，SAN60，上限99（神话0），DB0，Build0，MOV8，闪避基础DEX/2=35。此处只验证生成数值，**不是完成角色卡**：未分配的430点、记者专长、信用评级、装备及关系必须继续填写后才能宣布创建完成。

## 2. 从行动意图到检定

1. 询问要达到的结果、采取的方法和投入的时间；判断日常可行行动是否无需掷骰。
2. 选择技能和目标难度。普通≤技能；困难≤floor(技能/2)；极难≤floor(技能/5)。成功等级与任务达标是两件事。
3. 确认奖励/惩罚骰、可否消耗幸运、失败后能否孤注一掷。幸运消耗是可选配置，不能默认启用。
4. 读骰时先处理大成功/大失败，再判断等级；这些特殊规则的适用条件应查当前规则段，不能单凭普通阈值函数覆盖所有场景。
5. 结算已声明的目标与后果，记录资源和成长资格。

来源PDF71–77。NPC相关抵抗能力用于设定静态难度时，<50通常普通、50–89困难、≥90极难（PDF71）；这不表示每次面对NPC都应额外掷一次对抗骰。

技能65：阈值65/32/13。测试32为困难，33为普通，13为极难；若任务要求极难，32仍失败。没有普遍的“成功等级每升一级伤害翻倍”。

### 奖励骰与孤注一掷

奖励/惩罚骰共享同一个位，仅增加十位，选择组合后的较低/较高百分骰；十位00且个位0按100。不能模拟成两枚独立d100取优。普通对抗先比成功等级，再按普通对抗的同级程序；战斗平手见下一节（PDF76–77，其中PDF76已目视对应书页68）。

孤注一掷需要新的投入、方法或风险理由，是最终追加尝试。KP应先说明失败会怎样恶化。战斗、伤害、SAN、理智损失、幸运及普通对抗不能随意套该程序。失败后同一目的换技能也不自动获得无限免费重试（PDF72、76、87）。

## 3. 近战操作与平手

先说明攻击目标；防御者选择闪避、反击或合适的战技反击。双方比较成功等级，而非直接比较骰面大小。

| 情况 | 判定 | 结果 |
|---|---|---|
| 攻击对闪避 | 攻击必须取得更高成功等级 | 同级时闪避成功 |
| 攻击对反击 | 反击必须取得更高成功等级 | 同级且攻击成功时攻击方胜 |
| 双方都失败 | 不把平手优先权误作命中 | 双方均未有效击中 |
| 战技对闪避/反击 | 使用对应近战优先权 | 赢得声明的控制效果；反击胜可伤害 |

来源PDF87–89。测试：双方都是普通成功，防御选闪避则攻击落空，选反击则攻击者命中。不得改为“谁技能高谁赢”。

战技先明确缴械、压制、挣脱等目标，再比较Build。施术者比目标低1/2级分别受1/2惩罚骰，低至少3级不能按常规战技发动；体格更高不因此自动获奖励骰（PDF88–89）。不能把一句“我抓手腕”直接裁定为永久解除敌方所有攻击。

极难攻击的伤害需按能否贯穿、武器特性和是否反击查条文，不能把普通技能的极难成功奖励泛化。枪械另外核对射程、发射次数、瞄准、掩体、故障与弹药；PDF102列射程普通/两倍困难/四倍极难等摘要，完整连射与自动武器程序仍需回读第6章，禁止仅凭摘要宣布完成自动火力结算。

## 4. 伤害、濒死与恢复

每次受伤按**单次实际伤害**判断重伤，另记最大HP、当前HP、重伤、昏迷、濒死与医疗时间。达到最大HP一半为重伤；最大HP15时阈值8，不是7。重伤导致倒地并做CON检定以保持清醒。已有重伤且HP归零进入濒死；多次轻伤合计归零是昏迷，不能自动当成同样的濒死状态（PDF102–104）。官方Wiki已交叉核对：单次伤害大于或等于最大HP立即死亡；本地译本把等号遗漏，执行时按官方条文修正，见末节。

| 医疗阶段 | 程序与时间 | 来源PDF |
|---|---|---|
| 普通急救 | 受伤1小时内；成功恢复1HP；追加尝试按相应限制 | 103 |
| 医学治疗 | 一次至少1小时；通常成功恢复1d3HP；非当天治疗难度提高 | 103 |
| 濒死 | 濒死后的下一轮末开始每轮CON，失败死亡；急救先稳定，再接受医学 | 103–104 |
| 急救暂时稳定 | 暂时1HP；每小时CON，失败再次濒死；不是治愈重伤 | 103 |
| 无重伤自然恢复 | 1HP/天 | 104 |
| 重伤自然恢复 | 每周CON；成功1d3，极难2d3；环境与医疗改变奖励/惩罚骰 | 104 |

重伤恢复达到极难成功，或当前HP回到最大值一半以上，才按该节解除重伤标记。临时稳定与真正恢复分别记账，不许用“睡了一晚”跳过濒死医疗。

## 5. SAN与失控时段

先确定是否存在需要SAN检定的刺激和规定损失，例如0/1d4。成功也可能有损失；失败不是固定扣相同数值。SAN检定通常不加奖励/惩罚骰，也不许用幸运支付修改；大失败按相应最大损失处理（PDF133）。

- 单次损失至少5：做INT检定。成功理解其可怕意义，触发临时疯狂；失败压抑理解，不因该次门槛触发临时疯狂。临时疯狂时长1d10小时（PDF134）。
- 一游戏日累计损失达到五分之一：检查不定性疯狂。战役记录应保留本游戏日的计数基准及累计损失；“游戏日”需按规则中的休息/恢复语境确定，不能为逃避门槛随意在午夜清零（PDF134–135）。
- 疯狂发作与潜在疯狂分开。即时发作有1d10轮程序，临时疯狂持续1d10小时，二者不是同一计时器（PDF135–136）。发作中不再继续扣SAN的规则也不要误套到整个潜在疯狂期。
- SAN上限99−神话；归零按游戏规则处理角色去留。游戏的疯狂机制不能当成现实精神健康诊断（PDF134–135）。

规则许可的短暂失控是已约定机制的一部分；提前确认表现边界，优先让玩家在机械限制内叙述。KP不能把这一许可扩展成替玩家作长期人格、信念或关系选择。

## 6. 追逐与成长

追逐先做速度骰：步行/奔跑CON，汽车驾驶用驾驶；普通/困难不改MOV，极难+1，失败−1。逃脱者调整后明显快于追赶者可直接脱离，否则建立地点链和起始间隔。地点代表叙事片段，不是固定米数（PDF115）。

追逐轮按DEX顺序。每个参加者行动点=1+自身调整后MOV−最慢**参加者**MOV。最慢者可能是逃跑者；不要误读译文中的“最慢追逐者”。例如MOV5与7分别有1与3点。移动、障碍、谨慎通过与攻击均应实际记账，不能拿3点理解为无条件穿越3个障碍。记录地点ID、连接、障碍、各方位置和本轮剩余点（PDF116–117）。

幕间技能成长（PDF79）：符合资格的成功使用给一个标记，同一技能本次幕间只检一次；本译本规定使用奖励骰不获得该标记。对抗只有获胜者有资格，信用评级与神话不使用此成长标记。成长骰高于当前技能或>95时加1d10，可超过100；不能把成长骰按普通成功率方向判断。成长后重算半值/五分之一。达到90的SAN奖励须核对达标时机，避免每次幕间重复发放。

## 7. 来源冲突与现场查证

这份本地译本PDF29的角色算例有算术不一致，PDF103把单次立即死亡条件写为“超过最大HP”，与[官方伤害规则](https://cocwiki.chaosium.com/rules/hit-points-wounds-and-healing.html)的“大于或等于”冲突；本页采用官方条件，并将第一次濒死CON时机修正为下一轮末；不要把译文示例当作验证器预期值。PDF135的概述时长应结合PDF136详细程序阅读。PDF116中文“追逐者”与同页英文participant不一致，应保留问题记录。

官方复核入口：[Chaosium规则Wiki](https://cthulhuwiki.chaosium.com/rules/skill-rolls-and-difficulty-levels.html)、[资源页](https://www.chaosium.com/call-of-cthulhu-resources/)。当前未完成全部官方勘误与本地三个核心译本逐条比对。自动火力、载具碰撞、法术/魔典、怪物能力及特殊时代职业不在本页已验证程序内。
