# Fate Condensed与Blades：叙事动作的具体结算

两套系统独立使用。本页补充各自入口，不能把压力、相位、标签或骰池的同名概念互换。网络来源核查日期2026-09-06。

## Fate Condensed：行动与相位

4dF各面按−1/0/+1，加技能后与对抗比较：低于为失败，相等平手，高1–2成功，高至少3为出色成功。先选克服、创造优势、攻击或防御，再查该动作对应结果；攻击平手得到助力而不造成命中伤害。创造新相位成功通常给一次免费援引，出色给两次。相位援引可+2或重掷全部四骰；同一相位的付费援引不能在同一掷骰中重复，免费援引另有例外。参见[Taking Action](https://fate-srd.com/fate-condensed/taking-action-rolling-dice)。

原创判读例：技能3、骰和−1，总值2，对抗2。开锁的克服平手应谈小代价；攻击平手不能直接造成2伤害。两种情况虽然数字相同，机械结果不同。使用相位时须说明它如何影响这次行动，不能仅因写在卡上就永远加2。

## Fate Condensed：场景、压力与失败控制

复杂任务可用挑战；竞争互斥目标但不直接伤害用竞赛；具备相互伤害能力且意图伤害用冲突。Condensed压力每格吸收1阶，可同时用多格；未吸收完则退出场景。区域之间无阻碍的邻接移动通常可伴随行动，受阻时查克服。防御只要叙事上可行就能反应，不套D&D一反应次数。参见[Challenges, Conflicts, and Contests](https://fate-srd.com/fate-condensed/challenges-conflicts-and-contests)。

原创记录样式：`区域=码头 / 本交换已行动 / 身体压力[1,1,0] / 后果=无 / 相位“倾斜货箱”免费援引1 / 命运点2`。遭到2阶命中且仅剩一个空压力格时，不能勾一格后忽略余下1阶；要处理足够后果或接受退出。后果恢复、认输时机及命运点结算须打开对应完整条目，不用“回合结束清零”代替。

## Blades：风险与效果是两个轴

玩家声明目标并选择符合举措的行动；GM设position与effect，再算骰池。队友协助花1压力给+1d；自我推动花2压力或接受魔鬼交易可再获+1d，这二者不能同时为同一次行动提供该奖励骰。魔鬼交易代价无论成败都会发生。4/5通常带后果，controlled档还有撤回/改法等特定选项，不能与risky结果机械等同。参见[Action Roll](https://bladesinthedark.com/action-roll)。

原创例：强行撬门可能风险高但效果足够，伪装成访客可能风险低却只能进前厅。GM不应为了阻止玩家使用高技能直接夺走行动选择权；应解释此方法能做多少、暴露什么危险。

## Blades：抵抗与护甲

抵抗本身有效，骰子决定压力代价：6减最高骰；暴击清除1压力。GM先说明抵抗把后果降低还是完全避免。一个后果只能抵抗一次，多后果可以分别决定；先掷骰看价格再决定是否抵抗不合规则。适用护甲可勾格减轻后果，选择下一次任务负载时恢复护甲。参见[Resistance & Armor](https://bladesinthedark.com/resistance-armor)。

原创例：已告知“伤害3抵抗后降为2”，测试最高骰5，结果是伤害2并加1压力；不是骰5未达6所以抵抗失败。另有“警报暴露”后果时，这次抵抗不会自动把警报一起取消。

## Blades：时钟与停工

时钟表示持续障碍或逼近的危险。命名为要解决的障碍，避免限定玩家方法；复杂程度可用4/6/8格。单次足以结算的障碍无需强行拆钟。危险、竞赛、联动、拉锯和势力钟有不同用途。参见[Progress Clocks](https://bladesinthedark.com/progress-clocks)。

停工按报酬→热度→纠葛→停工活动处理，之后回自由行动；不能把任务中的行动骰结果直接套作恢复或长期项目收益。具体恢复、放纵恶习、费用和额外活动查各子条目。参见[Downtime](https://bladesinthedark.com/downtime)。

原创记录样式：`行动类型 / 骰池构成 / 风险 / 效果 / 结果 / 后果列表 / 哪项被抵抗 / 压力变化 / 时钟变化 / 护甲勾选`。检查恢复后的状态是否保留其他未抵抗后果。尚未完整核验各剧本、帮派升级、创伤、闪回费用与停工经济，不将本页作为完整角色认证。
