# BRP

本地 `BRP-基础角色扮演.pdf` 与 `BRP4th半自动角色卡v0.4.xlsx` 需匹配书内版本，自动卡名称不能认证规则版本。

官方 [版本历史](https://brp.chaosium.com/version-history/) 区分旧版和 Universal Game Engine；[ORC入口](https://www.chaosium.com/orc-license/) 指向适用的内容文档。不要将2020旧SRD的使用条件与新文档混用。

BRP 规则依可选模块变化。建模前登记属性范围、成功/特殊成功、对抗方式、伤害与护甲、命中部位、疲劳、技能点、超常能力、成长与恢复。和CoC共享百分骰谱系不表示年龄、技能基础值、幸运或理智规则通用。

当前仅有资料入口与开头抽样，任何具体角色合法性与战斗裁定须补查章节。
