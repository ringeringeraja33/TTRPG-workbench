# D&D 2024：SRD 5.2.1操作参考

来源为本地官方英文`SRD_CC_v5.2.1.pdf`，以下简称SRD。所有页码是PDF页序；当前提取页眉数字与所列页序一致，但不推及其他规则书。官方下载与版本入口：[D&D SRD](https://www.dndbeyond.com/srd)，书目[DND-SRD](../bibliography.md#dnd-srd)。这是规则释义和原创算例，SRD许可证与署名见[第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 1. 检定与修正的分层

属性调整值=floor((属性−10)/2)。d20检定分为属性检定、豁免、攻击，通常d20+属性调整值+适用的熟练加值+其他修正≥DC/AC即成功。不要在没有熟练时添加熟练加值；同一熟练加值不能因两项相关技能重复添加（SRD6–8）。

| 层 | 先检查什么 | 常见错误 |
|---|---|---|
| 是否掷骰 | 是否有不确定且有意义的失败 | 所有日常动作强制检定 |
| 类型 | 检定、豁免还是攻击 | 自然20对所有检定自动成功 |
| 修正 | 属性、熟练/专精、装备及效果 | 把熟练加值再加到普通武器伤害 |
| 优劣势 | 有任意优势和任意劣势则抵消 | 2个优势减1个劣势仍有优势 |
| 结果 | 总值与DC/AC比较；攻击自然1/20例外 | 只看骰面高低 |

只有一个优势或劣势类别时掷2d20取高/低，同类不叠骰。两类同时存在时回到1d20，不按数量相减。英雄激励可在掷后立即重掷任意一个骰并采用新结果；在优劣势的两个d20中只重掷所选一枚（SRD7–8）。

测试：攻击加值+5、AC16，普通命中率50%，优势75%，劣势25%。这是命中概率，不是含暴击、抗性、武器精通、优势获取成本的完整DPR。

## 2. 回合账本与攻击

每轮按先攻处理回合。在自己的回合分别记移动、一个动作、由具体能力允许的至多一个附赠动作；反应消耗后到自己下回合开始才恢复。额外攻击属于攻击动作内的攻击次数，不是额外完整动作。不能自行用动作兑换第二个附赠动作（SRD10及战斗章）。

攻击程序：选射程内合法目标→检查视线与掩护→确定修正及优劣势→攻击骰→命中后伤害与特效→记录资源、反应和条件。半掩护给AC/敏捷豁免+2，四分之三+5，全掩护不能直接作为目标；多个掩护取最高，不累加（SRD15）。

远程超普通射程但未超最大射程通常劣势，超最大射程不能攻击。被近处敌人牵制的远程攻击包括法术攻击，须检查该敌人距离、能否看见攻击者及失能状态，不只看目标是否在近处。借机攻击消耗反应，要求看见生物离开触及范围；撤离、传送及不使用自身移动/动作/附赠动作/反应的强制位移另有豁免（SRD15）。

命中加值不等于伤害加值。普通武器命中加属性与熟练，伤害通常只加对应属性；暴击把伤害骰掷两遍，加值不翻倍。例如2d6+3暴击为4d6+3，非4d6+6。其他随攻击的伤害骰按规则一并检查（SRD16）。

## 3. 擒抱、推撞与版本隔离

2024的徒手打击可选伤害、擒抱、推撞。擒抱/推撞由目标选择力量或敏捷豁免，DC=8+攻击者力量调整值+熟练加值；不是默认双方运动/特技对抗。擒抱需要空手，目标不能比自己大超过一个体型；推撞可推开5尺或使其倒地，同样有体型限制。逃脱另查Grappling条目，别把一次建立擒抱视为永久锁死（SRD190）。

例：力量16、一级熟练+2，擒抱DC13。对方可用力量或敏捷豁免选择较合适者。角色的运动专精不能在没有特例时直接把此DC再提高2。

## 4. 伤害、死亡与休息

伤害先做一般加减/倍率调整，再抗性减半向下取整，再易伤翻倍；同种抗性不叠加。测试：伤害23，先固定减4，再抗性再易伤，结果floor(19/2)×2=18，不能先把抗性与易伤“抵消”得19（SRD17）。

临时HP先吸收伤害，不与旧临时HP相加；重新获得时选择保留哪一份。治疗不恢复临时HP，临时HP不能让HP0角色苏醒。当前HP最多恢复到最大值；“血ied/Bloodied”仅表示半血或更低，本身无通用减值（SRD16、18）。

HP归零先查即时死亡：角色承受伤害后超过当前HP的余量≥最大HP即死亡。最大12、当前6，伤害18即可满足；这与CoC的单次重伤机制不同。普通怪物通常0HP死亡，GM可以对个体使用角色程序（SRD17）。

死亡豁免中的自然1算两次失败，自然20恢复1HP；0HP再次受伤产生失败，暴击产生两次；单次伤害达到最大HP会死亡。Help动作配DC10感知（医药）可稳定；稳定仍昏迷且0HP，不再做死亡豁免，若受伤则取消稳定；未治疗1d4小时后恢复1HP（SRD18；完整豁免累计时机连同SRD17末段读取）。

| 休息 | 收益与限制 | 来源 |
|---|---|---|
| 短休 | 1小时；开始至少1HP；花生命骰逐枚恢复骰值+CON，每枚最低1；按能力恢复资源 | SRD187 |
| 长休 | 至少8小时，通常至少6小时睡眠；开始至少1HP；全部HP与已消耗生命骰恢复；力竭减1 | SRD185 |
| 短休中断 | 掷先攻、施放非戏法、受伤导致中断且无收益 | SRD187 |
| 长休中断 | 同类事件及1小时体力活动会中断；已休至少1小时可得短休收益；续接须查该条完整要求 | SRD185 |

不能把2014版“长休恢复一半生命骰”写进5.2.1。角色能力的短休恢复量也要逐项核对，不能所有次数池一起回满。

## 5. 施法审查顺序

1. 确认职业施法能力、可用/已准备法术、法术位与施法来源；种族/专长免费次数与法术位分账。
2. 检查施法时间和触发条件；反应法术必须实际触发，不能任意插入。
3. 核对目标、射程、视线、遮挡及V/S/M成分；具体法术效果必须回读单独条目。
4. 检查本回合是否已消耗一个法术位施法。5.2.1限制是**一回合只能消耗一个法术位来施法**；免费施法、戏法与在其他人的回合使用反应要分别判断（SRD105）。
5. 检查专注、持续时间、结束条件和每次效果的触发时点。需要至少1分钟施法的过程每回合使用Magic动作并维持专注；中断失败但不消耗法术位（SRD105）。
6. 结算攻击或目标豁免；记录槽位、专注对象、持续时间及目标状态。不能只写“施法成功”。

本页不替代专注完整条目、法术列表或职业准备表。执行具体法术前必须加载该条目；不能用同名旧版法术的记忆填空。战士Action Surge在此版额外动作**不能是Magic动作**（SRD48）。

## 6. 创建与升级核验

创建顺序：职业→背景/物种/语言→属性→阵营与细节。标准数组15、14、13、12、10、8；掷属性4d6去最低共六次；购点27，8–15对应0/1/2/3/4/5/7/9点。方法不能混用（SRD19–21）。

背景列出三个属性：其中一个+2另一个+1，或三个各+1，上限20。不要自动补2014版物种属性加值。背景同时带起源专长、技能、工具与装备选择。选择钱就不能再免费领取该组装备（SRD21、83）。

每项核验保留来源层：职业等级给生命骰、豁免、训练和职业能力；背景给指定资源；物种给体型/速度/特性；专长给独立效果。一级与兼职进入某职业的熟练项不同，例如兼职战士不直接获得一级战士全部豁免和重甲训练（SRD47）。

升级按“总等级”和“职业等级”分列。熟练加值通常随总等级，职业能力看该职业等级；法术位另查兼职表，不能把两个职业每张表的槽位简单相加。本轮完整验证例见[一级战士](../../assets/examples/dnd2024-fighter.md)。
