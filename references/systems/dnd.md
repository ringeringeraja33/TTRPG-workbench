# D&D：3.5、2014、2024 分开

本地 `3R核心书1——玩家手册.pdf` 等为3.5候选；5E DMG/MM 与不全书分别查书内版权和具体条目。CHM 文件更新日期不能证明采用2024规则；不要把索引版本当规则版本。

公开入口：[D&D SRD](https://www.dndbeyond.com/srd)。本次检查页面列 SRD5.2.1；2024规则与SRD5.2.1关联，2014与SRD5.1关联。SRD 不包含全部商业书选项。下一次用户指定“最新版”仍需刷新。

构建时查验官方 `SRD_CC_v5.2.1.pdf`。本次逐条查看 PDF20–24；对应印刷页号可在提取正文中看到20–24，PDF21另作目视验证，页码仅适用于此版本。

创建核查锚点：21页含标准数组、27点购买、背景调整、属性修正；20页含来源熟练、起始装备、物种；22–23页含衍生字段、施法和升级。属性调整依该版本背景，不直接套2014种族加值。

基线点购：8/9/10/11/12/13/14/15对应0/1/2/3/4/5/7/9。15,14,13,12,10,8共27点；修正用向下取整((分数−10)/2)。这只验证基础分配，完整角色还需背景合法增益、职业、物种、装备、熟练、法术等。

查询先分检定/攻击/豁免，天然骰例外和优势/劣势依各条文；专注、反应、附赠动作、武器精通、力竭等高混版风险项逐条读对应版本。遭遇预算、休息恢复与法术描述不可凭跨版记忆填入。

输出短模组需要完整怪物数据来源、胜负外目标和撤退路径；没有核查的数据明确为原创或待定。
