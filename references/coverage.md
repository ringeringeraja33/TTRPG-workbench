# 覆盖与限制

2026-09-06：覆盖等级依据已完成的特定规则核查和行为演练，文件存在或开头抽样不能证明全书掌握。用户本地藏书清单另行维护。

能力等级：A = 有正文证据和实际任务样例，限明确范围；B = 有可读材料或已读公开核心，仅适合按需查证；C = 仅定位/抽样或格式未解，不能认证角色或完整主持规则。

新增系统先完成：来源/版本登记 → 核心结算与例外 → 创建及成长 → 战斗/资源/恢复 → GM 程序 → 一张角色和一个场景演练。通过什么就标记什么，保留失败与资料缺口。
