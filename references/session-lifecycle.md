# Session preparation and handoff

Adapted from [gm-apprentice session-prep](https://github.com/AntTheLimey/gm-apprentice/blob/b9912ea7219e55215ce0c2f87247e410ab8d903a/skills/session-prep/SKILL.md), AntTheLimey, under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This file is licensed under the same terms. Changes: removed vault-specific commands, replaced staged elicitation with the current user's requested autonomy, and integrated the local ledger.

1. Reconcile the previous wrap-up with saved campaign state. Distinguish actual events, unused plans and unconfirmed possibilities. Resolve contradictions explicitly; never promote an unused plan to canon.
2. Gather the active characters, open threads, unresolved rules and current scenario facts. Read a prior play log when no reliable wrap-up exists, labelling the resulting recap as reconstructed.
3. Plan the session's focus, character opportunities and likely scenes. Make concrete proposals within the requested scope; ask only about decisions that materially change it. Persist accepted decisions as preparation proceeds.
4. Verify scene connections, source references, resources and unresolved assumptions. Separate the GM plan from player material.
5. Handoff a concise opening situation, the next decision, the saved revision and outstanding questions. After play, record actual outcomes and deferred threads for the next preparation cycle.
