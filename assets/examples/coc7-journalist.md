# CoC7核心点数法：记者示例

原创建议角色，不代表玩家已选。使用本地《COC7th核心规则书v1.2.1.pdf》，1920年代、28岁、记者，无扩展，无幸运消耗房规。以下为指定测试属性，**未实际投骰**。角色林蔚调查港区账目，受失踪工人家属委托；关键连接建议为保存第一篇报道的旧笔记本，需玩家确认。

STR50 CON60 SIZ65 DEX70 APP55 INT75 POW60 EDU70，幸运50。20–39岁EDU改善一次，指定测试骰60，不改善。HP12/12，MP12/12，SAN60/99（神话0），DB0，Build0，MOV8。生成公式见[CoC程序](../../references/systems/coc7-procedures.md)。

## 操作验证与状态

普通图书馆检定指定骰40，达到困难成功；极难任务仍未达标。获得普通成功使用标记后，幕间成长指定骰81，高于80，追加指定1d10=4，则技能84、困难42、极难16。若此次使用有奖励骰，按该本核心成长条文不授予同一成长标记；成长资格独立于“骰子成功”。

遭受一次6伤害时达到最大HP一半，为重伤；当前HP6，并检查倒地和CON。先后受3、3伤害虽也剩6HP，两次都未达到重伤门槛，不自动产生重伤。两种状态须分别保存。

此卡已完成属性与点数法技能配置、职业范围和衍生值核验；开团前仍需玩家接受人物设定、KP确认背景物品及信用评级资产，并按团规设置可用技能上限。完整购买与真实骰生成未包含在本示例。
