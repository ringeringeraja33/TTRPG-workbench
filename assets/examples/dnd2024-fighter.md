# 可复算角色：一级人类战士

全部选项是原创建议示例，不代表用户已经选择。规则固定为英文SRD5.2.1，无兼职、无房规，标准数组。来源页码为本地官方PDF页序。人物名艾琳，28岁，守序善良，前边境士兵；追查失踪补给队，同行理由是保护同路旅人。

## 创建台账

| 项目 | 选择 | 依据 |
|---|---|---|
| 职业 | Fighter1；力量/体质豁免；选择察觉、求生熟练 | SRD47 |
| 背景 | Soldier；运动、威吓熟练；骰子套组；Savage Attacker | SRD83 |
| 物种 | Human；中型；速度30尺；额外洞悉熟练；Skilled起源专长 | SRD86–87 |
| Skilled三项 | 历史、游说、医药熟练 | SRD87 |
| 语言 | 通用语、矮人语、精灵语 | SRD20 |
| 战斗风格 | Defense：穿甲时AC+1 | SRD88 |
| 武器精通 | Greatsword、Flail、Javelin | SRD48、91 |

数组按STR15 DEX14 CON13 INT8 WIS12 CHA10分配；Soldier选力量+2、体质+1，最终17/14/14/8/12/10。调整值+3/+2/+2/−1/+1/+0。没有额外物种属性加值。

最大HP12=10+CON2，当前12，生命骰1d10，熟练+2。先攻+2，被动察觉13。豁免：力量+5、敏捷+2、体质+4、智力−1、感知+1、魅力+0。

技能完整列表：运动+5；特技+2、巧手+2、隐匿+2（链甲使相关隐匿检定劣势）；奥秘−1、历史+1、调查−1、自然−1、宗教−1；驯兽+1、洞悉+3、医药+3、察觉+3、求生+3；欺瞒+0、威吓+2、表演+0、游说+2。熟练来源没有重复领取；未熟练技能保留相应属性调整值。

## 装备与攻击

职业选装备A：链甲、巨剑、连枷、8标枪、地城探索套组、4GP。背景选A：矛、短弓、20箭、骰子套组、医疗包、箭袋、旅行服、14GP。合计18GP，无额外购物；具体套组内容按SRD装备条目打开，不暗中赠送盾牌。

链甲基础AC16，满足STR13要求，加Defense得17。链甲不再加敏捷，未持盾。巨剑攻击+5、伤害2d6+3；连枷+5、1d8+3；标枪+5、1d6+3，投掷30/120尺。矛+5、单手1d6+3；短弓+4、1d6+2。选取三种精通不等于给所有武器启用精通；使用其具体效果前查SRD90。持巨剑需要双手。

## 有限资源和时机

- Second Wind：2/2，以附赠动作恢复1d10+1HP，上限12；短休恢复一次使用次数，长休全回（SRD48）。
- Savage Attacker：每回合一次武器命中时可掷两组武器伤害骰选一组，不能把两组加起来，也不是每次攻击一次（SRD87）。
- Human：完成长休获得Heroic Inspiration；示例设刚完成长休，目前1份（SRD86）。
- 一级没有Action Surge、Tactical Mind、Extra Attack或子职，不提前给二/三/五级能力。

## 局部验证场景

指定测试输入：巨剑攻击d20=11，11+5=16，对AC16命中。普通伤害骰2与4，合计9。若使用Savage Attacker，再给定另一组1与6，选择较优组得10；第一次组的骰不能任意与第二组拼接。伤害资源应记录该回合已使用该专长。

另一次自己回合前生命6/12，Second Wind测试输入d10=8，计算6+8+1=15但只恢复到12，次数2→1，占用本回合附赠动作。完成短休后次数1→2；如果原来0/2则只回到1/2。此例属于程序测试，没有实际投骰，也没有用户战役数据。
